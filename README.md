## 🎯 О проекте

Задача: автоматически считывать две строки цифр с фотографии счетчика — **показания** и **серийный номер** (возле штрих-кода). Фото делается пользователем в реальных условиях: возможны блики, наклоны, грязь на стекле.

**Ключевые особенности:**
- Детекция каждой цифры и разделителя отдельно (не OCR «из коробки»).
- Устойчивость к размытию и наклонам за счет аугментации.
- Модели загружаются один раз при старте сервера.
- Асинхронная обработка запросов (FastAPI + `asyncio.to_thread`).
- Нагрузочное тестирование (Locust).

## 🏗 Архитектура

```
Пользователь (Telegram) 
        │
        ▼
   FastAPI (REST API)
        │
        ├──► YOLO #1 (сегментация) — выделяет области «показания» и «номер»
        │
        ├──► YOLO #2 (детекция) — распознает цифры показаний
        │
        └──► YOLO #3 (детекция) — распознает цифры серийного номера
        │
        ▼
   Постобработка: сортировка боксов по X → сборка числа
        │
        ▼
   Ответ: {"reading": "001235", "serial": "1234567"}
```

**Почему три модели?**
- Сегментация точнее выделяет область на сложном фоне.
- Отдельные детекторы для показаний и номера позволяют использовать разные пороги уверенности и не путать классы.

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/[твой-username]/meter-reader.git
cd meter-reader
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить API

```bash
uvicorn api:app --host 0.0.0.0 --port 8000
```

API будет доступно по адресу `http://localhost:8000`. Документация — `http://localhost:8000/docs`.

### 4. (Опционально) Запустить Telegram-бота

```bash
python bot.py
```

> **Примечание:** для работы бота нужен токен от [@BotFather](https://t.me/BotFather). Токен указывается в файле `.env`.

## 🚀 Использование

### Через API

```bash
curl -X POST "http://localhost:8000/predictions" \
     -F "file=@path/to/meter.jpg"
```

**Ответ:**
```json
{
  "reading": "001235",
  "serial": "1234567"
}
```

### Через Telegram-бота

1. Отправить боту команду `/start`.
2. Отправить фото счетчика.
3. Получить распознанные значения.

## 📊 Результаты

Нагрузочное тестирование проводилось с помощью **Locust** на GPU **NVIDIA GTX 1650 (4 GB)**.

| Метрика | Значение |
| :--- | :--- |
| **RPS (запросов/сек)** | ~22 |
| **p50 (медиана)** | ~400 мс |
| **p95** | ~700 мс |
| **GPU-Util** | ~35% |

> Узкое место — не GPU, а предобработка и постобработка на CPU. Дальнейшая оптимизация: батчинг, Triton Inference Server.
